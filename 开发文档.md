### 第一阶段：需求拆解与选型设计

#### 1. 核心业务功能
*   **基础管理**：图书 CRUD、分类管理、读者（学生/教职工）管理。
*   **借阅流程**：借书、还书、续借、逾期罚款计算。
*   **系统管理**：角色权限控制（RBAC）、日志审计、登录登出。
*   **查询统计**：热门图书排行、借阅记录查询。

#### 2. 技术栈选型
| 模块 | 技术选型 | 选型理由 |
| :--- | :--- | :--- |
| **开发语言** | Java 17 / 21 LTS | Long-term support, 性能优异 |
| **后端框架** | Spring Boot 3.2+ | 现代化标准，自动配置 |
| **安全认证** | Spring Security + JWT | 无状态会话，符合前后端分离架构 |
| **ORM 框架** | MyBatis-Plus | 高效开发，减少 XML 冗余 |
| **数据库** | MySQL 8.0 | 成熟稳定，事务支持完善 |
| **前端框架** | React 18 + TypeScript | 类型安全，生态丰富 |
| **UI 组件库** | Ant Design Pro v5/v6 | 企业级中后台首选 |
| **HTTP 客户端** | Axios + React Query | 缓存管理，请求拦截 |

#### 3. 架构分层规范
*   **Controller**：仅处理参数校验和 HTTP 响应封装。
*   **Service**：核心业务逻辑层，事务控制在此。
*   **Mapper/Repository**：数据访问层，禁止在此写业务逻辑。
*   **DTO/VO**：数据传输对象，严格隔离实体类与接口对象。

### 第二阶段：数据库设计 (MySQL 8.0)

采用规范化设计，包含必要的索引和外键约束。为防误操作，增加 `is_deleted` 软删除字段。

```sql
-- 创建数据库
CREATE DATABASE IF NOT EXISTS lib_sys DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE lib_sys;

-- 1. 用户与角色表 (RBAC)
CREATE TABLE t_user (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键 ID',
    username VARCHAR(50) NOT NULL UNIQUE COMMENT '用户名',
    password VARCHAR(255) NOT NULL COMMENT '密码 BCrypt 加密',
    nickname VARCHAR(50) COMMENT '昵称',
    status TINYINT DEFAULT 1 COMMENT '状态 0-禁用 1-正常',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    deleted_flag TINYINT DEFAULT 0 COMMENT '软删除标志'
) ENGINE=InnoDB COMMENT='用户信息表';

CREATE TABLE t_role (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(50) NOT NULL UNIQUE COMMENT '角色名 (ADMIN, LIBRARIAN)',
    code VARCHAR(50) UNIQUE COMMENT '角色代码',
    description VARCHAR(255)
) ENGINE=InnoDB COMMENT='角色表';

-- 用户角色关联表
CREATE TABLE t_user_role (
    user_id BIGINT NOT NULL,
    role_id BIGINT NOT NULL,
    PRIMARY KEY (user_id, role_id)
) ENGINE=InnoDB COMMENT='用户角色关联';

-- 2. 图书基础信息
CREATE TABLE t_book (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    isbn VARCHAR(20) NOT NULL UNIQUE COMMENT 'ISBN 号',
    title VARCHAR(100) NOT NULL COMMENT '书名',
    author VARCHAR(100) COMMENT '作者',
    publisher VARCHAR(100) COMMENT '出版社',
    total_count INT DEFAULT 0 COMMENT '总馆藏数',
    available_count INT DEFAULT 0 COMMENT '当前可借数',
    category_id BIGINT COMMENT '分类 ID',
    cover_url VARCHAR(255) COMMENT '封面 URL',
    location_code VARCHAR(20) COMMENT '索书号位置',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    deleted_flag TINYINT DEFAULT 0
) ENGINE=InnoDB COMMENT='图书信息表';

-- 3. 借阅记录
CREATE TABLE t_borrow_record (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    book_id BIGINT NOT NULL,
    user_id BIGINT NOT NULL COMMENT '借阅人 ID',
    borrow_date DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '借出时间',
    due_date DATETIME NOT NULL COMMENT '应还时间',
    return_date DATETIME COMMENT '实际归还时间',
    status TINYINT DEFAULT 0 COMMENT '状态 0-借阅中 1-已还 2-逾期 3-丢失',
    fine_amount DECIMAL(10,2) DEFAULT 0.00 COMMENT '罚款金额',
    INDEX idx_user_status (user_id, status),
    FOREIGN KEY (book_id) REFERENCES t_book(id),
    FOREIGN KEY (user_id) REFERENCES t_user(id)
) ENGINE=InnoDB COMMENT='借阅记录表';
```

#### 2. 核心代码示例

**A. 请求拦截器 (`api/request.ts`)**
注入 Token，统一错误提示。
```typescript
import axios from 'axios';
import { message } from 'antd';

const instance = axios.create({ baseURL: '/api', timeout: 10000 });

// 请求拦截：携带 Token
instance.interceptors.request.use(config => {
  const token = localStorage.getItem('token');
  if (token) {
    config.headers['Authorization'] = `Bearer ${token}`;
  }
  return config;
}, error => Promise.reject(error));

// 响应拦截：处理 401 未授权
instance.interceptors.response.use(res => res.data, err => {
  if (err.response?.status === 401) {
    message.error('登录已过期，请重新登录');
    window.location.href = '/login'; // 强制跳转
  } else {
    message.error(err.message || '请求失败');
  }
  return Promise.reject(err);
});

export default instance;
```

import React, { useEffect, useState } from 'react';
import { Table, Button, Space, Modal } from 'antd';
import { PlusOutlined } from '@ant-design/icons';
import { getBookList } from '@/api/modules/book';

export default function BookListPage() {
  const [loading, setLoading] = useState(false);
  const [dataSource, setDataSource] = useState([]);
  const [visible, setVisible] = useState(false);

  // 模拟 fetch 数据
  const fetchData = async () => {

    try {
      const res = await getBookList({ page: 1, pageSize: 10 });
      setDataSource(res.rows); // 假设后端返回分页结构
    } finally {
      setLoading(false);
    }
  };

  useEffect(() => {
    fetchData();
  }, []);

      <Space style={{ marginBottom: 16 }}>
        <Button type="primary" icon={<PlusOutlined />} onClick={() => setVisible(true)}>

        dataSource={dataSource} 
        loading={loading} 
        rowKey="id"
        columns={[
          { title: 'ID', dataIndex: 'id' },

          }
        ]}

### 第五阶段：联调测试说明

#### 1. 启动指南
*   **后端**：执行 `mvn spring-boot:run`，默认端口 8080。
*   **前端**：执行 `npm install` -> `npm start`，默认端口 3000。

#### 2. 测试策略
1.  **单元测试**：
    *   使用 JUnit 5 对 Service 层的 `reduceStock` 方法进行测试，确保并发下库存不会扣减为负数。
    *   覆盖边界条件（如库存不足时抛出特定异常）。
2.  **集成测试**：
    *   编写 Postman 脚本集合：`Auth Test` (登录获取 Token) -> `Book Ops` (增删改查) -> `Record Ops`。
    *   检查 `Authorization` Header 是否正确透传。
3.  **压力测试**：
    *   使用 Apache JMeter 模拟 100 个并发用户同时借书同一本书，观察数据库死锁情况及应用日志报错情况。

#### 3. 部署注意事项
*   **环境变量**：将数据库账号密码放入 `application-prod.yml` 并设置 `spring.profiles.active=prod`。
*   **HTTPS**：生产环境务必配置 Nginx 反向代理并开启 SSL。
*   **监控**：建议接入 Prometheus + Grafana 监控 JVM 内存及 CPU 使用率。
